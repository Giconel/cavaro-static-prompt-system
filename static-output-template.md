# Static Output Template

Every output generated by this system must follow this exact structure. Do not skip sections. Do not reorder sections.

---

## Output Structure

---

### 1. Quick Visual Read

- **Category:** [e.g. knit cardigan, linen blouse, midi dress]
- **Colour:** [specific colour name — not just "blue", say "dusty navy"]
- **Fabric / Texture:** [fabric type and visible texture]
- **Fit:** [relaxed / fitted / oversized / tailored]
- **Silhouette:** [A-line / straight / wrap / boxy / etc.]
- **Neckline:** [exact neckline]
- **Sleeves:** [length and style]
- **Closures:** [buttons, zip, tie — number, size, colour]
- **Length:** [hip / midi / ankle / etc.]
- **Pattern / Print:** [solid / or describe print precisely]
- **Other Details:** [pockets, trim, ruching, smocking, embroidery, etc.]
- **Product accuracy risks:** [note any details that an image generator is likely to get wrong — e.g. button count, print scale, sleeve style]
- **Selected angle:** [state the angle]
- **What the angle must communicate visually:** [one sentence — what must the viewer feel or understand from the image alone]

### 5. Final Visual Checklist

Run this check before delivering the output. Every item must be confirmed across all 5 options.

- [ ] Product colour is accurate in every prompt description
- [ ] Fabric and texture are correctly described in every prompt
- [ ] Fit, silhouette, and length match the product in every prompt
- [ ] Neckline and sleeve details are correct in every prompt
- [ ] Buttons, zips, or closures are described correctly in every prompt
- [ ] Pattern or print is accurately described in every prompt (if applicable)
- [ ] Each option uses a different setting, model type, pose, or composition
- [ ] Each subject is a realistic Australian woman aged 35–55
- [ ] No option uses model or editorial styling
- [ ] Every prompt stands alone — no external context needed to use it
- [ ] Overlay hook stays within the Meta safe zone in every option
- [ ] Negative prompt is included in full for every option
- [ ] All 5 prompts are ready to paste into an image generator
